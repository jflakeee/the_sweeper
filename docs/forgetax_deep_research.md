# ForgeTax: 반복 플레이·도박적 위험 선택 딥리서치

프로젝트: the_sweeper | 조사일: 2026-11-05 UTC | 대상: GraveYardDev의 Steam ForgeTax, 앱 5245810

## 1. 결론과 조사 범위

ForgeTax의 벤치마크 가치는 단순한 확률 강화에 있지 않다. 이미 가치가 생긴 검을 계속 강화할지, 납부에 쓸지, 유물에 투자할지 결정하게 하고, 유물 조합으로 결과의 의미까지 바꾸는 데 있다. 분석상 핵심은 **손실 가능성 × 중단 선택 × 실패의 재활용 × 조합 발견**이다.

이 문서의 ‘중독성’은 다시 플레이하고 싶게 만드는 설계상의 유인이다. 임상적 중독이나 이용자의 정신 상태를 진단하지 않는다. ‘도박성’은 가상 자산을 위험에 노출하는 플레이 구조를 뜻하며 법적 분류가 아니다. 현금 베팅·환전 구조는 이번 확인 자료에서 확인하지 못했다.

공식 상점 설명, 개발자 업데이트와 Steam 공개 리뷰를 조사했다. 직접 실행·프레임 단위 영상 관찰·실제 난수 코드 검증은 하지 않았다. 아래 심리·디자인 해석과 제안 수치는 관찰 사실과 구분한다. 개발 중인 영상은 출시된 시스템의 증거로 사용하지 않았다.

## 2. 확인된 시스템

공식 상점 기준: 검을 단조해 가치를 높이지만 파괴될 수 있다. 같은 검의 단조 10회가 Frenzy 충전에 연결되며 다음 타격에서 발동한다. 짧은 비파괴 구간이 생긴다. 검은 용에게 바치는 공물과 유물 획득에 모두 쓰여 자원 배분이 충돌한다. 유물은 추첨 티켓과 조합을 바꾼다. [S1]

2026-10-06 개편은 시작 유물 3개 중 1개 선택, Damage/Hold/Break를 성장으로 전환하는 효과를 도입했다. 예를 들어 Damage가 다음 Great의 추가 강화에 기여하고, Hold도 다음 Great를 키울 수 있다. 강화 상한은 +99지만 외형 변화는 +20에서 끝난다. 확률 감소는 상대 감소다. 공지 예시에서 40%를 15% 줄이면 34%다. [S2]

같은 날 후속 복구 패치: Undertaker’s Chalice는 파괴된 검 최고 가치의 30%를 공물로 보전한다. Broken Holy Sword와 Dawn Scabbard는 함께 강화 수치 70% 계승과 Frenzy 충전 7회를 제공한다. 납부 실패 다음 날에도 기본 검 3개를 받는다. 먼저 나온 공지의 Broken Holy Sword 20%는 후속 패치의 30%로 바뀌었으므로 혼용하지 않는다. [S3]

이 수치는 조사한 공지 버전의 값이다. 현재 실행 파일을 열어 재검증한 값은 아니다. 강화 단계별 기본 확률표와 모든 효과의 적용 순서는 공식 자료만으로 확정하지 않았다.

## 3. 반복 플레이를 만드는 구조: 분석

| 구조 | 플레이어가 하는 판단 | 다시 시도할 이유 | 무너지는 조건 |
|---|---|---|---|
| 가치가 붙은 검 | 지금 확보할까, 한 번 더 칠까 | 직접 만든 성과가 다음 보상의 기반 | 손실만 커지고 판단 정보가 부족 |
| 공물과 유물의 경쟁 | 이번 회차 생존과 다음 회차 성능 중 무엇을 살까 | 다른 투자 순서를 시험 | 초반 투자 한 번이 회복 불가능한 파산 |
| 실패 결과의 전환 | 내 조합에서 이 결과는 정말 실패인가 | 같은 결과도 빌드에 따라 달라짐 | 특정 실패를 반복하는 것이 항상 최선 |
| Frenzy 접근 | 남은 충전까지 버틸까 | 가까운 목표와 잠깐의 해방감 | 충전 직전 손실이 과도하게 반복 |
| 유물 조합 | 어떤 효과를 함께 쓰면 결과가 바뀔까 | 자신이 규칙을 이해하고 바꿨다는 성취 | 정답 조합 하나로 모든 판단 종료 |
| 수치·수집 성장 | 더 강한 검과 다른 조합을 만들까 | 기록과 발견의 목표 | 숫자만 증가하고 경험은 동일 |

### 3.1 한 번의 클릭보다 ‘멈춤’이 중요하다

확률 보상만 있으면 반복 추첨에 가깝다. ForgeTax는 이미 가진 검의 가치를 다음 시도에 걸게 해 선택의 무게를 만든다. 하지만 계속 누르는 것이 항상 정답이면 이 긴장도 사라진다. 중단, 다른 검 사용, 유물 투자에 각각 합리적인 상황이 있어야 한다.

모바일 이식에서 중요한 것은 탭 횟수가 아니라 **결정 한 번으로 달라지는 결과**다. 짧은 연출 뒤 결과·확률·현재 가치·중단 시 확보량을 읽을 시간이 필요하다. 반복 타격의 물리적 피로를 재미로 오해하면 안 된다.

### 3.2 가장 독창적인 장점은 실패의 의미를 바꾸는 것이다

일반 강화에서는 실패가 진행을 늦춘다. 실패 전환형 조합에서는 이번 손실이 다음 성공을 준비할 수 있다. 플레이어가 결과를 해석하고 계획할 여지가 커진다.

그러나 복구 기능이 희귀 유물에만 있으면, 해당 유물을 얻지 못한 판이 시작부터 불리하게 느껴진다. 기본 복구를 보편적으로 제공하고 유물은 복구 방식이나 활용 전략을 바꾸게 하는 편이 조합 다양성에 유리하다는 설계 가설을 세울 수 있다.

### 3.3 초반과 후반의 문제가 반대다

초반에는 선택이 결과를 바꾸기 전에 자원이 고갈될 수 있다. 후반에는 강한 조합 완성 뒤 선택이 불필요해질 수 있다. 개발자도 10월 11일 공지에서 조합을 즐기기 전 종료되는 판과, 조합 완성 후 반복되는 플레이를 개선 대상으로 밝혔다. 검 고유 능력과 용 전투는 당시 개발 중인 계획이다. [S4]

따라서 초반은 선택을 해볼 여유, 후반은 서로 다른 목표와 효율 경쟁이 필요하다. 후반 난도를 숫자로만 올리면 완성한 조합을 빼앗긴 느낌만 줄 수 있다.

## 4. 도박적 긴장과 확률 해석

| 요소 | 이 게임에서 분석되는 역할 | 설계상 주의 |
|---|---|---|
| 판돈 | 이미 강화한 검의 가치와 재조달 비용 | 실제 손실 범위를 행동 전에 제시 |
| 불확실 보상 | 강화·Great·파괴 등 결과 | 표시 확률과 실제 처리의 일치 |
| 선택적 위험 확대 | 가치가 오른 검으로 계속 시도 | 중단의 보상도 충분해야 함 |
| 복구 추구 | 잃은 자원을 다음 검으로 되찾기 | 실패 직후 유료 재도전 유도와 결합하지 않기 |
| 임계점 기대 | Frenzy까지 남은 진행 | 근접 상태를 과장하는 연출 피하기 |
| 확률 개입 | 유물·티켓으로 결과 분포 변경 | 기본값보다 적용 후 최종값을 표시 |

이는 행동 설계에 대한 해석이며, 모든 이용자에게 같은 심리 반응이 생긴다는 실증 결과는 아니다. 의도적인 아슬아슬한 실패 연출이나 확률 조작이 구현됐다는 증거도 확보하지 않았다.

### 4.1 한 번의 낮은 확률과 누적 위험은 다르다

설명용 가정: 매회 독립이고 파괴 확률이 항상 10%라면 10회를 모두 버틸 확률은 0.9^10 ≈ 34.9%다. 적어도 한 번 파괴될 확률은 약 65.1%다. 실제 ForgeTax는 강화 단계·유물·상태에 따라 분포가 달라질 수 있으므로 이 숫자를 실제 게임 확률로 적용하면 안 된다.

### 4.2 기대값이 높아도 생존에는 나쁠 수 있다

가정: 확보 자산 900, 현재 검 1,000, 납부 목표 1,800. 지금 납부하면 통과한다. 다음 시도의 성공 확률이 70%, 성공 가치 1,600, 파괴 가치 0이라면 검의 기대값은 1,120으로 증가하지만 납부 성공 확률은 확정에서 70%로 낮아진다.

평균 수익을 높이는 행동과 이번 판을 살리는 행동은 다르다. 게임이 이 차이를 드러낼수록 판단의 재미가 생긴다. 현금·상점 크레딧·공물 보전은 사용처가 달라 하나의 기대값으로 무조건 합산하면 안 된다.

### 4.3 복구는 적정 도전 횟수를 바꾼다

성공하면 현재 가치의 m배, 실패하면 r배를 보전하는 단순 모형에서 계속 시도의 기대값은 V×[p×m+(1−p)×r]이다. m>r일 때 현재 가치 V보다 커지는 조건은 p>(1−r)/(m−r)다.

예를 들어 m=1.6이면 보전이 없을 때 기준 성공 확률은 62.5%, r=0.3이면 약 53.8%다. 복구가 강해질수록 반복 시도가 유리해진다. 따라서 복구 추가 후 성공 확률·보상 배율·회차 자원까지 함께 검토해야 한다. 이 계산은 자체 가정이며 실제 게임의 다중 결과와 공물 전용 보전을 재현하지 않는다.

### 4.4 티켓 추가와 확률 증가를 혼동하지 않기

가상의 티켓이 성공60·유지20·파괴20일 때 성공 티켓10개를 추가하면 성공률은 70/110≈63.6%다. 70%가 아니다. 실제 효과 순서가 더 복잡할 수 있으므로 UI에는 티켓 개수와 함께 계산된 최종 분포를 보여주는 것이 좋다.

0% 표시도 구분해야 한다. 반올림된 0%와 시스템적으로 불가능한 0%는 다르다. 후자만 ‘파괴 없음’으로 표현하고, 작은 양수는 0.1% 미만 등으로 표시한다.

## 6. the_sweeper 적용 제안

다음은 신규 설계 제안이며 현재 프로젝트에 구현됐다는 뜻이 아니다.

### 6.1 채택할 것

1. **확보와 추가 탐사의 경쟁**: 확보한 기초 보상은 보존하고, 이번 탐사의 추가 보상 일부만 다음 위험에 노출한다. 계속할 때의 추가 이득과 손실을 같은 화면에 표시한다.
2. **실패 전환형 모듈**: 실패에서 다음 탐사의 정보·충전·대체 재료를 얻는다. 모든 실패가 이익이 되는 무한 순환은 막는다.
3. **예측 가능한 해방 구간**: 일정한 행동 뒤 안전한 채굴 기회를 주되 빠른 연타 실력으로 보상량이 크게 갈리지 않게 한다.
4. **세 가지 성격의 빌드**: 안정형은 낮은 변동, 성장형은 후반 효율, 복구형은 손실 후 회복에 특화한다. 어느 하나도 진행 필수품으로 만들지 않는다.
5. **이번 판의 학습 결과**: 종료 화면에 어떤 선택과 조합이 결과를 만들었는지 짧게 설명한다. 다음 목표는 새로운 전략을 제안한다.

### 6.2 그대로 복제하지 않을 것

| 위험한 이전 방식 | 개선 방향 |
|---|---|
| 주요 장비와 영구 성장이 한 번에 소멸 | 탐사 중 임시 보너스에 손실 집중 |
| 같은 행동 수백 회로 수치만 확대 | 구간마다 다른 목표·도구·경로 선택 |
| 보호 유물을 못 얻으면 판이 무너짐 | 기본 복구 제공, 유물은 복구의 활용법 변경 |
| 실패 직후 결제로 원상복구 제안 | 실패와 과금 분리, 구매 대상은 명확한 콘텐츠·외형 |
| 모바일 빠른 연타가 효율을 결정 | 누르기 유지·행동 예약, 중요한 결정은 별도 확인 |
| 확률을 작은 숫자로만 표시 | 예상 결과와 위험 자산량, 적용된 보호 효과 병기 |

### 6.3 최소 검증 실험

첫 실험은 시스템을 한꺼번에 늘리지 않는다. 동일한 탐사에서 A안은 고정 보상, B안은 중단 가능한 추가 위험 선택을 제공한다. 보상 기대값과 콘텐츠량을 비슷하게 맞춘다. 첫 성공 후 자발적 재시도, 위험 선택의 이해도, 종료 만족도, 실패 직후 이탈을 함께 본다.

다음 실험에서만 복구형 모듈을 추가한다. 모듈을 가진 판과 못 가진 판의 통과율 격차, 자원 고갈 전에 의미 있는 결정을 한 횟수, 특정 모듈 선택 쏠림을 확인한다. 체류시간 증가만으로 개선 판정하지 않는다.

| 지표 | 확인하려는 문제 | 해석 주의 |
|---|---|---|
| 첫 의미 있는 선택까지 시간 | 설명이 재미를 가리는가 | 짧기만 하면 이해가 부족할 수 있음 |
| 중단 선택률과 납부 성공률 | 확보가 실제 선택지인가 | 계속 도전률이 높을수록 좋은 것은 아님 |
| 실패 후 회복 가능 판 비율 | 연속 손실로 선택이 사라지는가 | 모든 실패 무효화도 긴장을 제거 |
| 빌드별 선택·완주 분포 | 정답 빌드가 지배하는가 | 숙련도·등장 빈도 통제 필요 |
| 결과 이해도·공정성 응답 | 결과를 납득하는가 | 체감만으로 난수 정확성을 검증할 수 없음 |
| 터치 오입력·중복 처리 | 모바일에서 손실이 조작 탓인가 | 결과 연출 중 입력 중복 방지 필요 |

확률 검증 로그는 시도 직전 상태, 적용 효과, 최종 확률, 결과, 버전을 남긴다. 조건이 다른 시도를 한데 합쳐 공시 확률과 비교하면 잘못된 결론을 낼 수 있다. 저장 복구에서는 이미 확정한 결과를 유지해, 새로고침이 의도치 않은 무료 재추첨이 되지 않게 설계한다.

## 7. 우선순위와 남은 확인

P0: 확률·손실·확보량 표시, 입력 오류 방지, 기본 복구, 저장 일관성.
P1: 실패 전환 조합, 확보와 투자 선택, 첫 성공 이후 다른 목표.
P2: 수집 외형·더 긴 성장·추가 연출. 핵심 선택이 재미있는지 확인하기 전에 확장하지 않는다.
